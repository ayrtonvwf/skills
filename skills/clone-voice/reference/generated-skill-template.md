# Generated skill template

The scaffold for `skills/write-as-<name>/SKILL.md`. The generated skill must be
**self-contained**: it embeds the voice profile and inlines the refusal rules, and never
reads back into `clone-voice/reference/` at runtime (the generator may be absent when it
runs).

When generating, replace every `<placeholder>`:

- `<name>` - the target name, kebab-cased for `name:` and the folder.
- `<Display Name>` - the human-readable target name.
- `<YYYY-MM-DD>` - the generation date, read from the system clock (`date +%Y-%m-%d`).
- `<embedded voice profile>` - the full contents of the voice profile (the filled-in
  `profile-template.md`), pasted inline.
- `<ethics banner>` - the banner block, copied verbatim from `refusal-rules.md`.
- `<refusal cases>` - the refusal cases block, copied verbatim from `refusal-rules.md`.

The fenced block below is the file to write.

````markdown
---
name: write-as-<name>
description: Rewrite text in <Display Name>'s writing voice. Trigger when the user asks to write, rephrase, or draft a message as <Display Name>, or invokes /write-as-<name>.
provenance:
  target: <Display Name>
  generated: <YYYY-MM-DD>
  source: supplied corpus analyzed by clone-voice
---

## Rewrite

If the request passes the refusal check, rewrite the input in the voice described by the
embedded profile. Preserve the meaning of the input; change only the voice. Apply the
**reproduce-exactly traits** faithfully - do not "clean up" habitual typos, missing
apostrophes, or capitalization quirks, since those are the voice. Match punctuation,
segmentation, greetings/sign-offs, emoji, and recurring expressions.

Output only the rewritten text unless the user asks for explanation.
````
